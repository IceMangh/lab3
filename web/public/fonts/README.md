# Шрифты

- Manrope Variable, веса 200–800 — интерфейс. [Исходник](https://github.com/google/fonts/tree/main/ofl/manrope).
- IBM Plex Mono Regular и Medium — номера вершин, веса, счётчики и стек DFS. [Исходники](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).

Шрифты размещены локально в WOFF2, содержат кириллицу и загружаются без запросов к внешним сервисам. Лицензии SIL Open Font License сохранены рядом в `Manrope-OFL.txt` и `IBMPlexMono-OFL.txt`.
