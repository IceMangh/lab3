# Текущий интерфейс

Доска занимает доступную высоту окна. Верхняя строка содержит выбор задачи, создание графа и настройки отображения. Боковая панель изменяет ширину и сворачивается. Слоганы, крупный заголовок и декоративный подвал удалены по запросу пользователя.

Текущие концепты: [тёмный](monochrome-dark.png) и [светлый](monochrome-light.png), оба 1536 × 1024. Концепты созданы для существующей лаборатории: полноэкранная доска, прежние названия задач и действий, чёрно-белые панели, Manrope и IBM Plex Mono, упругая координатная сетка. Светлый вариант сохраняет геометрию тёмного.

Тёмная тема: фон и доска `#0b0b0b`, панели `#111111`, текст `#f1f1f1`, активные элементы `#f5f5f5`. Светлая тема: фон и доска `#ffffff`, панели `#fafafa`, текст `#151515`, активные элементы `#161616`. Цвет сохраняется только у результатов раскраски и найденных компонент. Переключатель солнце/луна сохраняет выбор в браузере и обновляет сетку без сброса графа или воспроизведения.

Manrope 200–800 используется для интерфейса, IBM Plex Mono 400/500 — для номеров, весов и технических данных. WOFF2 размещены в `public/fonts/`, рядом лежат лицензии OFL. На десктопе высота шапки 84 px, строки задач 86 px, панели воспроизведения 82 px; начальная ширина инспектора 374 px. При сужении окна размеры уменьшаются, на телефоне инспектор располагается под доской. Нативные SVG-иконки используют общую палитру.

Граф и сетка разделены: SVG содержит интерактивные вершины и связи, Canvas 2D рисует упругую сетку с мелкими линиями, основными осями, точками и крестиками. При наведении появляется мягкая монохромная подсветка, узлы отклоняются и возвращаются пружинным движением. Изменение камеры не меняет данные графа. Колесо сохраняет точку графа под курсором, перетаскивание фона перемещает камеру. Анимация сетки останавливается в покое и отключается при `prefers-reduced-motion`.

Примеры рёбер и выбранная вершина на концептах иллюстративные: приложение сохраняет настоящий граф пользователя и его выбор. Тексты действий и порядок задач сохранены.

`concept.png` — исходный концепт первой версии, оставленный как архив. Его крупный заголовок, подвал и фиксированная рабочая область больше не используются.
